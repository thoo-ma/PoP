# Google Cloud Run — Audio Detection Service

## Runtime & Dependencies

- **Python 3.10** (slim Docker image)
- **Flask** — HTTP server
- **TensorFlow** (CPU-only) + **TensorFlow Hub** — model inference
- **YAMNet** — audio classification model (loaded from Kaggle Hub at startup)
- **librosa** — audio decoding and resampling
- **ffmpeg** + **libsndfile1** — system-level audio codec support
- **Gunicorn** — production WSGI server (1 worker, 4 threads, 60s timeout)

## Code Organization

```
google-cloud-run/
  app.py               ← Flask app: /detect endpoint, YAMNet inference
  Dockerfile           ← Container image build, model preloaded at build time
  requirements.txt     ← Production deps
  tests/
    requirements.txt   ← Test deps (ML only, no Flask)
    test_detection.py  ← Single-file YAMNet inference test
    test_batch_yamnet.py ← Batch test across all assets
    assets/            ← Test audio files
```

## Patterns

### Endpoint — `POST /detect`

**Request**:
- Header: `X-API-Key` (required — service-to-service auth, not Bearer token)
- Body: `{ "audio": "<base64-encoded>", "threshold": 0.5 }`

**Response** (200):
```json
{
  "detected": true,
  "confidence": 0.87,
  "mean_confidence": 0.42,
  "duration_seconds": 3.2,
  "num_frames": 6,
  "model_version": "yamnet-v1",
  "threshold_used": 0.5,
  "top_predictions": [{ "class": "Toilet flush", "confidence": 0.87 }, ...],
  "audio_size_kb": 48.5,
  "error": null
}
```

**Error responses**: 400 (missing/malformed), 401 (bad API key), 422 (audio too short — returns the full result with an `error` field), 500 (exception).

**Truncation**: audio longer than 30 s is silently truncated; this is intentional and not an error.

### Endpoint — `GET /health`

No auth required. Returns model load status.

**Response** (200):
```json
{ "status": "healthy", "model_loaded": true }
```

### Audio Constraints

| Constraint | Value |
|---|---|
| Input formats | `.wav`, `.mp3`, `.m4a`, `.flac`, `.ogg` (librosa + ffmpeg) |
| Resampled to | **16 kHz mono** (YAMNet requirement) |
| Min duration | 0.5 seconds |
| Max duration | 30 seconds (prevents timeout) |
| Encoding | Base64 for transit |
| Normalization | Peak-scaled if amplitude > 1.0 |

### Model

- **YAMNet** — Google's audio event classifier
- **Toilet flush** is class index **368**
- **Aggregation**: MAX across all frames (not the mean) — better sensitivity
- **Default threshold**: 0.5, tunable per request via the `threshold` parameter
- **GPU disabled** at startup (`CUDA_VISIBLE_DEVICES=-1`) — CPU-only for cost efficiency and horizontal scaling

### Integration Point

Called by `supabase/functions/detect-toilet-flush/index.ts`:

1. Edge function receives audio from the mobile app
2. Validates JWT auth + checks per-user daily rate limit (`flush_detections` table)
3. Forwards to Cloud Run: `POST ${CLOUD_RUN_URL}/detect` with `X-API-Key` header
4. Stores result in `flush_detections` table (detected, confidence, duration, model_version)

**Env vars** (set on Cloud Run service):
- `API_SECRET_KEY` — shared with edge function as `CLOUD_RUN_API_KEY`
- `MODEL_VERSION` — model identifier (default: `yamnet-v1`)

**Edge function env vars**:
- `CLOUD_RUN_URL` — e.g. `https://yamnet-detector-xxxxx-uc.a.run.app`
- `CLOUD_RUN_API_KEY` — must match `API_SECRET_KEY`

### Testing

```bash
cd google-cloud-run
python -m venv tests/venv
source tests/venv/bin/activate
pip install -r tests/requirements.txt
python tests/test_detection.py
python tests/test_batch_yamnet.py
```

Tests run YAMNet inference locally against audio files in `tests/assets/` — no API call or Flask server required. Drop test audio (any supported format) into `tests/assets/`.

### Logging Convention

Prefix with `[DETECT]` or `[DETECT_FLUSH]`, include milestones and user context:
```python
print(f"[DETECT] audio loaded: {duration:.1f}s, {len(waveform)} samples", flush=True)
print(f"[DETECT] inference complete: detected={detected}, confidence={confidence:.3f}", flush=True)
```

Use `flush=True` for unbuffered output in Cloud Run logs.

## Pitfalls

- **Service-to-service auth uses `X-API-Key`,** not Bearer tokens. Do not accept JWTs here — the edge function authenticates the user upstream.
- **Audio > 30 s is silently truncated.** Do not add a hard reject; existing callers rely on truncation.
- **GPU is intentionally disabled** (`CUDA_VISIBLE_DEVICES=-1`). Do not re-enable without a cost and scaling review.
- **Aggregation is MAX across frames,** not the mean. Do not revert to mean aggregation — sensitivity drops.
- **Single Gunicorn worker, 4 threads, 60 s timeout.** Do not increase the worker count without verifying memory headroom (the TensorFlow model footprint is ~50 MB resident).
